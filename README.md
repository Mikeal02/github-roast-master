# 🔥 What Is Roast My Git?

**Roast My Git** is an AI-powered GitHub profile analyzer that transforms repository data into brutally honest (and hilarious) developer roasts.

Simply enter a GitHub username.

The app analyzes:

- Repositories
- Programming Languages
- Commit Patterns
- Project Activity
- Profile Structure
- Repository Quality

Then an AI model creates a unique roast based on actual developer behavior.

# ⚙️ Getting Started

## Clone Repository

```bash
git clone https://github.com/<yourusername>/github-roast-master.git

cd github-roast-master
```

---

## Install Dependencies

```bash
npm install
```

---

## Environment Variables

Create a `.env` file:

```env
REACT_APP_GITHUB_TOKEN=your_github_token_here

REACT_APP_AI_API_KEY=your_ai_api_key_here
```

---

## Start Development Server

```bash
npm run dev
```

---

Application runs on:

```bash
http://localhost:5173
```
